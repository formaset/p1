# Система анализа цифрового двойника в реальном времени

Этот проект демонстрирует модульную архитектуру для синтетического цифрового двойника
сложной производственной системы. Анализатор включает генерацию потоковых данных,
предобработку, построение признаков, цифровой двойник, детектор аномалий и
онлайн-классификатор.

## Запуск

```bash
python -m digital_twin_rt.main
```

Лог в консоли отображает интегральные метрики и последнее состояние системы.
