# Цифровой двойник производственной системы

## Аннотация
Программа представляет собой высоконагруженную систему для непрерывного анализа телеметрии цифровых двойников сложных производственных объектов. Архитектура охватывает синтез и прием потоковых данных, их предобработку с нормализацией и сглаживанием шумов, выявление аномалий на основе статистических порогов, нечеткую классификацию технического состояния и многоуровневое хранение результатов. Поддерживается одновременная работа в потоковом и пакетном режимах, конфигурирование параметров конвейера через JSON, буферизация данных в памяти с последующей сериализацией на диск, а также CLI-оркестрация для автоматизации сценариев мониторинга и офлайн-аналитики. Решение ориентировано на устойчивую работу в режиме реального времени, обеспечивает масштабируемость, расширяемость компонентов конвейера и прозрачное логирование для инженерных команд.

## Структура
- `digital_twin/config.py` — конфигурация конвейера.
- `digital_twin/telemetry.py` — модель телеметрии и генерация синтетики.
- `digital_twin/stream.py` — асинхронный источник и буферизация событий.
- `digital_twin/preprocessing.py` — нормализация и скользящая статистика.
- `digital_twin/anomaly.py` — детектор аномалий.
- `digital_twin/classifier.py` — классификатор состояния.
- `digital_twin/storage.py` — долговременное и оперативное хранение.
- `digital_twin/orchestrator.py` — сборка конвейера и запуск.
- `main.py` — CLI для потокового и пакетного режимов.

## Запуск
Пакетный режим с генерацией N записей:
```
python main.py batch --count 50
```

Потоковый режим на ограниченное время (в секундах):
```
python main.py stream --seconds 10
```

Можно передать пользовательский JSON-конфиг через `--config`.
